# SUNDAY PACE MUSIC 24시간 라이브 상태 보고

- 보고: Mac 세션 (sundaypacemusic-e0)
- 점검 방식: 읽기만 함 (서버, 방송 설정, 프로세스는 바꾸지 않음)

## 1. 확인 시각
2026-11-18 22:50 JST (+0900)

## 2. 송출 상태: 송출 중 (Mac 쪽 기준)
판단 근거:
- 송출 스크립트 `~/streamtool/stream.sh`가 실행 중 (22:31:35 시작)
- 그 아래 ffmpeg 프로세스가 실행 중. 시작 시각이 같으므로 시작한 뒤로 재시작된 적 없음. CPU 약 75% 사용
- ffmpeg에서 YouTube RTMP 서버(포트 1935)로 TCP 연결이 열려 있음 (ESTABLISHED)
- `caffeinate -dimsu`가 함께 돌고 있어 Mac이 잠자기로 들어가지 않음
- 송출 파일: `SundayPaceMusic/001/_output/video.mp4` (약 369MB, 11/15 생성), 무한 반복 재생(`-stream_loop -1`)
- 인코딩 설정: H.264 3000kbps, 30fps, 키프레임 2초 / AAC 128kbps

## 3. 최근 오류
확인 불가. ffmpeg 경고는 로그 파일 없이 터미널 창(s001)에만 출력되기 때문.
간접 근거: 스크립트는 ffmpeg가 끝나면 10초 뒤 다시 띄우는데, 22:31 이후 ffmpeg가 새로 시작된 흔적이 없음. 그 뒤로는 송출이 끊긴 적이 없는 것으로 보임.
